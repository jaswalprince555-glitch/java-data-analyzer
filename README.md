# 📊 Java Data Analyzer

A beginner-friendly terminal application built in Java that takes integer input from the user and evaluates it using core programming operators. This project demonstrates foundational knowledge of Java data types, terminal input handling, and logical evaluations.

## 🚀 Features
- **Interactive Input:** Utilizes the `Scanner` class to read and process user data from the terminal.
- **Arithmetic Operations:** Calculates and stores mathematical multiples.
- **Relational & Logical Evaluation:** Uses the logical AND operator (`&&`) to validate if the user's number falls within a specific target range (greater than 10 and less than 100).
- **Formatted Reporting:** Outputs a clean, concatenated string report directly to the console.

## 🛠️ Prerequisites
- Java Development Kit (JDK) installed on your machine.
- A terminal or IDE (like VS Code or IntelliJ IDEA).
